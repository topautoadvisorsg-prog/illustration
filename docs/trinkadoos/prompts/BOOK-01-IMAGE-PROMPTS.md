# Book 1 — *The Lantern Tree Went Dark* · image prompt set

**16 image prompts · for owner review · nothing rendered.**

Standing rules applied to every prompt below:

- Reference lock stated at the top of each prompt.
- **No text rendered into the illustration** — no story text, captions, titles, logos, page
  numbers or lettering. Text is added manually afterwards.
- A **real safe zone** in a naturally open part of the composition, still containing actual
  environment — never a parchment panel or blank block painted into the art.
- Composed as a **moment in motion**, not a static centred line-up.
- Only the characters **actually present** in the scene get references attached.
- No invented story elements. Scenes follow `01-ART-BRIEF/TRINKADOOS_LAYOUT_AND_ILLUSTRATION_BRIEF.md`.

The **Video Continuity Note** is a planning note about staging only. It is **not** a video prompt
and must never be pasted into a video model. See `VIDEO-PROMPT-RULES.md`.
