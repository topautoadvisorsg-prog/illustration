## Production-line convention — note for any tooling

The file says "delete every line that begins with `[`". The lines actually begin with a
**backtick**: `` `[SPREAD 4 · pp. 10–11 · image: …]` ``. A strip written to the stated rule
removes nothing. Any word count or export must filter on the backtick form.
